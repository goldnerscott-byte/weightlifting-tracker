# Weightlifting Tracker

A mobile-first React app for tracking weekly weightlifting workouts.

## Features

- **Weekly View**: Navigate between weeks with arrow buttons
- **Daily Workouts**: Organize exercises by categories
- **Exercise Tracking**: Log sets, reps, and weight for each exercise
- **Unit Toggle**: Switch between lbs and kg instantly
- **Smart Import**: Import previous workouts by category
- **Auto-Save**: All data saves instantly to browser storage
- **Responsive Mobile Design**: Optimized for phone screens

## Quick Start

### Deploy to Vercel
1. Push this code to GitHub
2. Go to vercel.com
3. Import your GitHub repository
4. Click Deploy
5. Get your live URL
6. Open on your phone!

## How to Use

### Week Overview
- Tap a day to see exercises
- Tap + to add categories
- Tap "Import Week" to import previous weeks

### Day Detail
- Tap weight/reps to edit
- Tap lbs/kg to toggle units
- Tap exercise name to delete or move
- Tap ➕ add to add another set

### Importing
- Use "Import" button in smart suggestions for single categories
- Use "Import Week" button to import entire weeks

## Categories

Back, Biceps, Calves, Chest, Core, Glutes, Hamstrings, Quads, Shoulders, Triceps

## Data Storage

All data is saved in your phone's browser storage (localStorage). Data persists even after closing the app.
